## Thermal Test Environment (Neel)

The test level is `Content/CameraTest1.umap`. It has one example object for each heat case Team 5 is standardizing (human, animal, vehicle, fire, building/wall, ground), plus a trapped survivor, flood water and a cold object. Everything is placed in front of `BP_ThermalCamera`, so one RGB/thermal capture pair shows every case.

| Object | Type | Heat (0-6) | Actor label(s) |
|---|---|---|---|
| Standing survivor | Human | 4 | `TT_Human_Standing_*` |
| Survivor trapped under debris | Human (debris = 1) | 4 | `TT_Human_Trapped_*` |
| Dog | Animal | 3 | `TT_Animal_Dog_*` |
| Car: body / cabin / tires | Vehicle | 3 | `TT_Vehicle_Car_Body`, `_Cabin`, `_Tire0-3` |
| Car: hood over engine, exhaust | Vehicle | 5 | `TT_Vehicle_Car_Hood_Engine`, `_Exhaust` |
| Campfire: flame | Fire | 6 | `TT_Fire_Flame` |
| Campfire: burning logs | Fire | 5 | `TT_Fire_Log0-2` |
| Damaged building wall | Building | 2 | `TT_Building_Wall_*` |
| Ground / dirt landscape | Ground | 1 | `Landscape` |
| Flood-water puddle | Water | 0 | `TT_Water_Puddle_Water` |
| Steel barrel in shade | Cold object | 0 | `TT_Cold_MetalBarrel_Barrel` |

All test actors are in the World Outliner folder **ThermalTest**. Each one has three Actor Tags:

- `Heat_<0-6>`: its heat value
- `ThermalType_<Type>`: Human, Animal, Vehicle, Fire, Building, Ground, Water, ColdObject or Debris
- `ThermalTest`: marks it as part of the test set

The thermal material or Team 5's heat component can read the heat value from the tag, for example `Actor Has Tag "Heat_4"` or by parsing the number after `Heat_`. The floating name labels above the objects are editor-only and hidden in game, so they never appear in captures.

The full list with temperatures and reasoning is in `Docs/ThermalHeatValues.csv`. That file can also be imported as a DataTable.

### Heat scale (0-6)

| Heat | Meaning | Approx. surface temp |
|---|---|---|
| 0 | Colder than ambient: flood water, shaded metal, sky | below 15 C |
| 1 | Ambient background: ground, dirt, rubble | 15-22 C |
| 2 | Sun-warmed structures: building walls, pavement | 22-30 C |
| 3 | Warm: animal fur surface, vehicle body, tires | 28-40 C |
| 4 | Human body | 32-37 C |
| 5 | Hot machinery: engine hood, exhaust, embers | 60-150 C |
| 6 | Open flame | above 300 C |

The scale is ordered, not linear in temperature. Each step is a level that should look clearly different in the thermal image. The real temperature gap between a person and an engine is much bigger than one step, but evenly spaced levels keep every case visible in grayscale.

### Rebuilding the environment

The environment is generated by `ThermalCameraTest/Scripts/BuildThermalTestEnvironment.py`. To rebuild it:

1. Open the project. The Python Editor Script Plugin is enabled in the `.uproject`; restart the editor once if it asks.
2. **Tools > Execute Python Script...** and choose `Scripts/BuildThermalTestEnvironment.py`.
3. **File > Save All**.

Running the script deletes its previous objects and rebuilds them around wherever `BP_ThermalCamera` currently sits, so it is safe to re-run after moving the camera. Settings at the top of the script:

- `DISTANCE_SCALE`: spreads objects farther or closer
- `GROUND_Z_OVERRIDE`: forces a ground height
- `ADD_LABELS`: turns the floating labels on or off

### Limitations / next steps

- Objects are built from engine basic shapes as placeholders. Team 5's thermal actors (human, animal, vehicle, fire, building, ground) can replace them while keeping the same heat values.
- Heat is one value per part. There is no gradient across a surface (for example, a warmer face than clothing) and no cooling over time.
- Next steps: swap in Team 5's actors, capture paired RGB/thermal images of every case for the deliverables, and add a second scene at night, where the ground cools and the contrast changes.
